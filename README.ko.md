# YEONFEEL Keyboard

[English](README.md)

YEONFEEL Keyboard는 한글 입력 품질에 중점을 두고 개발한 안드로이드
입력기(IME)입니다. 당연히 영어 입력도 지원합니다. 기본 키보드의 한글 입력이 아쉬운
기기에서 사용하기 위해 Claude와 함께 처음부터 새로 작성했습니다. 완전한 오프라인
동작이 설계 원칙이라 앱이 `INTERNET` 권한 자체를 요청하지 않습니다. 입력
내용과 클립보드, 사용 기록은 기기 내부에 유지됩니다. 릴리스 APK는 약 1.2MB입니다.
런타임 의존성은 `androidx.core` 하나입니다. 다른 안드로이드 기기에서
삼성키보드의 대안을 찾고 있다면, 잘 찾아 오셨습니다!

## 입력

자판은 두벌식(표준), 단모음(10키), 천지인, 나랏글, 나랏글 중앙, 영어
QWERTY/드보락 여섯 가지입니다. 3x4 자판은 국가표준 배열을 따릅니다. 숫자
길게 누르기와 컴팩트 기호판도 갖췄습니다.

한글 조합 오토마타는 안드로이드 의존성이 없는 순수 Kotlin 코드로
`hangul/`에 분리되어 있습니다. 빠른 타이핑 중 롤오버 같은 엣지 케이스까지
JVM 단위 테스트로 검증합니다.

자잘한 편의 기능으로 됬 → 됐 자동 교정 옵션, 시프트 두 번 탭 캡스록,
스페이스바 스와이프 언어 전환, 연타 판정 시간 조절, 자동 교정을 백스페이스로
되돌리는 동작이 있습니다. ㅋ은 길게 누르고 있으면 손을 뗄 때까지
연속으로 입력됩니다.

재미용 옵션도 두 가지 있습니다. 하나는 ㅋㅋㅋ 연타를 ㅋㅋㅎㅋ처럼 바꿔
신세대 말투로 보이게 하고, 다른 하나는 피처폰 천지인 세대의 ㅋㅋㅋㅋㄱㅋㅋ
오타를 재현합니다. 둘 다 기본으로 꺼져 있고, 활성화 하더라도 비밀번호 
입력란에서는 동작하지 않습니다.

## 교정 (실험실 메뉴, 기본 꺼짐)

실험실 메뉴에서 교정 기능 두 가지를 켤 수 있습니다. 둘 다 기기 안에서만
동작합니다.

- 터치 보정은 사용자가 각 키를 실제로 누르는 위치를 키별 가우시안 모델로
  학습해, 키 경계 부근의 모호한 터치를 다시 판정합니다.
- 어절 교정은 키 인접도를 반영한 편집거리로 2만 8천 어절 빈도 사전에서
  교정 후보를 제안합니다. 66만 어절 블룸 필터가 실제로 있는 단어를 다른
  단어로 바꾸는 오교정을 막습니다.

## 데이터 처리

- 클립보드 이력은 Android Keystore 키(AES-256-GCM)로 암호화해 저장합니다.
  기기가 지원하면 키는 하드웨어에 보관됩니다.
- 비밀번호 입력란에서는 키 미리보기, 타점 수집, 문자를 바꾸는 모든 옵션이
  꺼집니다.
- 터치 보정용 타점 표본은 키 단위로만 저장하고 순서와 시각을 기록하지
  않습니다(만료 관리용 날짜만 남깁니다). 7일이 지난 표본은 삭제합니다.
  저장 파일을 통째로 읽어도 입력한 문장은 복원되지 않습니다.

## 커스터마이징

- 라이트·다크 테마와 고대비 4종, 키 글자 크기 3단계.
- 키보드 높이·여백·길게 누르기 지연 시간의 드래그 조절.
- 가로 화면·대화면용 분할 키보드, 한 손 모드, 편집 가능한 툴바.
- SSH 클라이언트용 터미널 도구 줄(Esc, Tab, Ctrl, Alt, 방향키).
- 이모지 패널(1,082종, 스킨톤 기억, 초성 검색)과 감정별 카오모지 패널.

## 빌드 및 실행

```sh
./gradlew test assembleDebug          # 단위 테스트 + 디버그 APK
adb install app/build/outputs/apk/debug/app-debug.apk
```

빌드는 프로젝트의 Gradle 래퍼(Gradle 8.13)로 합니다. 별도 설치한 최신
Gradle은 현재 AGP 버전과 호환되지 않습니다. 설치 후 YEONFEEL Keyboard 앱을
열어 안내에 따라 키보드를 활성화합니다. minSdk는 23입니다.

## 프로젝트 구조

```
app/src/main/java/dev/badalab/yeonfeel/
├── hangul/       # 조합 오토마타·어절 교정기 (순수 Kotlin, JVM 테스트)
├── ime/          # InputMethodService, 렌더링, 레이아웃, 터치 모델
├── clipboard/    # Keystore 암호화 클립보드 이력
├── settings/     # 설정 화면 (View 기반 UI 킷)
└── debug/        # 타점 표본 저장소
scripts/          # 이모지 데이터·교정 사전 생성기
```
